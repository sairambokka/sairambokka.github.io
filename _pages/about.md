I am a cybersecurity researcher and software engineer specializing in the intersection of artificial intelligence and security. Currently, I work as a Software Engineering Intern at [Corca Research](https://corca.ai/), where I'm developing an innovative real-time hints feature for their mathematical software tool that makes typing mathematical equations simple and intuitive on computers.

## Research Interests

My research focuses on **Agentic AI and Cybersecurity**, exploring three key areas:

- **AI Agents for Offensive Security**: Developing autonomous agents capable of performing security assessments, vulnerability discovery, and penetration testing using advanced AI techniques.
- **AI Agents for Defensive Security**: Building intelligent systems for threat detection, incident response, and security monitoring using multi-agent architectures.
- **Security of Agentic AI Systems**: Investigating and developing security features to protect AI agent systems from adversarial attacks, prompt injection, and other emerging threats.

I am particularly interested in how large language models and multi-agent systems can be leveraged to automate complex security workflows while ensuring the AI systems themselves remain secure and trustworthy.

## Current Work

At Corca Research, I'm building an intelligent hints system that provides real-time mathematical assistance as users type equations. This feature leverages symbolic computation to analyze mathematical expressions and generate contextual suggestions, making complex mathematical notation more accessible. My work involves:

- Developing a real-time hints engine using Python and SymPy for symbolic mathematics
- Building TypeScript-based frontend integration for seamless user experience
- Implementing algorithms to parse and analyze mathematical expressions in real-time
- Creating intelligent suggestion systems that understand mathematical context and user intent
- Optimizing performance to deliver hints with minimal latency as equations are typed

This role combines my interests in AI and software engineering, applying computational mathematics to enhance user productivity and accessibility in mathematical documentation.
