## Overview

A powerful multi-agent system designed to scan web applications for security vulnerabilities. The system deploys specialized AI agents to evaluate different security domains, combining automated browser testing with AI-driven analysis to identify security gaps.

## Key Features

- **Multi-Domain Security Assessment**:
  - Frontend vulnerabilities (XSS, CSRF, CSP)
  - Network security (authentication, encryption, API security)
  - Real-time traffic analysis
- **Automated Browser Testing**: Selenium-based interaction with live applications
- **AI-Driven Analysis**: Intelligent vulnerability detection and risk assessment
- **Detailed Remediation Reports**: Actionable security recommendations

## Technologies

- Python (100%)
- CrewAI (multi-agent orchestration)
- Selenium (browser automation)
- NVIDIA AI/ChatNVIDIA (language models)
- Exa AI (web search)
- BeautifulSoup (HTML parsing)

## Security Coverage

- **Frontend Security**: Cross-Site Scripting (XSS), Cross-Site Request Forgery (CSRF), Content Security Policy violations
- **Network Security**: Authentication mechanisms, encryption protocols, API security
- **Traffic Analysis**: HTTP request/response inspection, DOM manipulation detection
- **Compliance**: Security best practices and standards validation

## Applications

- Security audits for web applications
- Continuous security monitoring
- Pre-deployment vulnerability assessment
- Security training and demonstrations
