## Overview

A full-stack financial analysis platform that leverages the Claude AI API to process and interpret financial data, delivering AI-generated insights through a responsive Next.js frontend. The application is containerized with Docker for consistent deployment.

## Key Features

- **AI-Powered Analysis**: Integrates the Claude AI API to process and interpret complex financial data
- **Responsive Frontend**: Built with Next.js and TypeScript for a fast, interactive user experience
- **Containerized Deployment**: Dockerized application for consistent and reproducible environments
- **Modular Architecture**: Clean TypeScript codebase with well-structured, reusable components

## Technologies

- **Frontend**: Next.js, TypeScript, React
- **AI Integration**: Claude AI API
- **Deployment**: Docker
- **Language**: TypeScript

This project demonstrates expertise in building AI-integrated full-stack applications with modern web frameworks and cloud-native deployment practices.
